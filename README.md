# AlegLiceu
 
AlegLiceu este o aplicație web care își propune să ajute elevii să aleagă liceul potrivit după clasa a VIII-a.
 
## Pentru cine este și cum se folosește
 
Aplicația este pentru elevii de gimnaziu care vor să se informeze înainte de a alege un liceu.
 
Momentan este disponibilă doar **pagina de start**, care conține:
 
- o bară de navigare de tip drop-down, pentru viitoarele meniuri ale aplicației;
- titlul și o scurtă descriere a aplicației;
- un buton către tutorial(urmeaza sa fie adaugat).
Pentru a folosi aplicația, deschide linkul de mai jos și apasă pe butonul „Meniu" pentru a vedea opțiunile de navigare. Celelalte pagini și funcționalități urmează să fie adăugate.

## Tehnologii folosite
 
- **HTML** – structura paginii de start;
- **CSS** – stilul paginii (paleta de culori, bara de navigare, butoane);
- **JavaScript** – planificat pentru funcționalitățile viitoare, încă neimplementat.
